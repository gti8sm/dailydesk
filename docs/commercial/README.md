# Modèles commerciaux DailyDesk

Trois documents à personnaliser pour chaque mairie (remplacer les passages
`[ENTRE CROCHETS]`), puis mettre en page dans votre traitement de texte :

| Fichier | Usage |
|---|---|
| `devis-modele.md` | Devis à remettre à la mairie (structure et libellés prêts, prix à caler) |
| `deliberation-modele.md` | Délibération du conseil municipal approuvant le projet et la demande de subvention |
| `note-opportunite-modele.md` | Note d'opportunité d'une page à joindre au dossier DETR/DSIL |

## Chronologie imposante (subvention DETR/DSIL)

Aucune dépense ne peut être engagée avant le dépôt du dossier (« commencement
d'exécution ») :

1. Remise du devis + note d'opportunité à la mairie
2. **Délibération** du conseil municipal (approuver le projet + autoriser la demande de subvention)
3. **Dépôt du dossier** DETR/DSIL sur Démarche Numérique (préfecture) — le devis et la note d'opportunité sont les pièces justificatives
4. **Signature du devis** et mise en service — après accusé de réception du dossier (attention : l'accusé ne vaut pas promesse de subvention, mais permet d'engager)

## Repères de prix (à ajuster)

- Mise en service (forfait unique) : 300-800 € HT selon population
- Abonnement annuel : 40-100 € HT/mois pour < 3 500 habitants (grille de l'app)
- Tablette garderie complète (11", coque renforcée, verre trempé, support) : 280-400 € HT
- Configuration tablette : ligne séparée, 30-60 min

## Aides mobilisables

- **DETR/DSIL** : formulaire unique sur Démarche Numérique, appel annuel
  (souvent oct. → janv. selon département). DSIL priorité n°4 : développement
  du numérique. Nécessite délibération + devis + note d'opportunité.
- **ANCT — Accompagnement numérique sur mesure** : communes < 3 500 hab,
  expert 3 mois, gratuit.
- **ANCT — Suite territoriale** (2026) : communes < 3 500 hab, socle de
  services numériques sécurisés — argument de contexte, pas un financement.
